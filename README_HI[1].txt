UP Khabar PWA starter

1) index.html, manifest.json aur sw.js ko ek saath rakhein.
2) Local file par install/PWA features kaam nahi karte; HTTPS hosting chahiye.
3) In files ko free static hosting (jaise GitHub Pages) par upload karne ke baad supported Android browser se Add to Home Screen karein.
4) Live headlines RSS proxy par nirbhar hain; availability/format badal sakta hai.
5) Admin form abhi local browser storage use karta hai. Isse sirf isi device par news save hoti hai. Sabhi users ko news publish/sync karne ke liye secure backend/database aur admin authentication configure karna hoga.
6) Google Play Store publishing ki alag developer registration fee ho sakti hai.
